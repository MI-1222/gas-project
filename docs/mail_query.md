# gmailクエリ

参考: [https://support.google.com/mail/answer/7190?hl=ja&co=GENIE.Platform%3DDesktop&oco=0](https://support.google.com/mail/answer/7190?hl=ja&co=GENIE.Platform%3DDesktop&oco=0)

> [!Note]
> クエリの一部に数字を使用する場合は、スペースまたはハイフン（`-`）で数字を分割できます。
> ピリオド（`.`）は小数点を表します。
> たとえば、「`01.2047-100`」は「`01.2047`」と「`100`」の 2 つの数字とみなされます。

| 検索演算子                                                                                                                                                                                                                       | 説明                                                                                                                                                                                | 例                                                                                                                                                 |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `from:`                                                                                                                                                                                                                          | 特定の送信元からのメールを検索します。                                                                                                                                              | `from:me`, `from:amy@example.com`                                                                                                                  |
| `to:`                                                                                                                                                                                                                            | 特定の宛先へのメールを検索します。                                                                                                                                                  | `to:me`, `to:john@example.com`                                                                                                                     |
| `cc:`, `bcc:`                                                                                                                                                                                                                    | `[Cc]` または `[Bcc]` 欄に特定の宛先を含むメールを検索します。                                                                                                                      | `cc:john@example.com`, `bcc:david@example.com`                                                                                                     |
| `subject:`                                                                                                                                                                                                                       | 件名の単語やフレーズでメールを検索します。                                                                                                                                          | `subject:dinner`, `subject:anniversary party`                                                                                                      |
| `after:`, `before:`, `older:`, `newer:`                                                                                                                                                                                          | 指定した期間に送信されたメールを検索します。                                                                                                                                        | `after:2004/04/16`, `after:04/16/2004`, `before:2004/04/18`, `before:04/18/2004`                                                                   |
| `older_than:`, `newer_than:`                                                                                                                                                                                                     | 指定の期間より古いまたは新しいメールを検索します。期間は `d`（日）、`m`（月）、`y`（年）で指定します。                                                                              | `older_than:1y`, `newer_than:2d`                                                                                                                   |
| `OR` または `{ }`                                                                                                                                                                                                                | 1つ以上の検索条件に一致するメールを検索します。                                                                                                                                     | `from:amy OR from:david`, `{from:amy from:david}`                                                                                                  |
| `AND`                                                                                                                                                                                                                            | 検索条件のすべてに一致するメールを検索します。                                                                                                                                      | `from:amy AND to:david`                                                                                                                            |
| `-`                                                                                                                                                                                                                              | 検索条件からメールを除外します。                                                                                                                                                    | `dinner -movie`                                                                                                                                    |
| `AROUND`                                                                                                                                                                                                                         | 2 つのキーワードが近くにあるメールを検索します。2 つの単語間に許容可能な単語数を指定します, 引用符を追加すると、入力した単語の順序と一致するメールを検索します                      | `holiday AROUND 10 vacation`, `"secret AROUND 25 birthday"`                                                                                        |
| `label:`                                                                                                                                                                                                                         | いずれかのラベルの付いたメールを探します。                                                                                                                                          | `label:friends`, `label:important`                                                                                                                 |
| `category:`                                                                                                                                                                                                                      | 受信トレイのカテゴリを使用している場合に、いずれかのカテゴリのメールを探します。                                                                                                    | `category:primary`, `category:social`, `category:promotions`, `category:updates`, `category:forums`, `category:reservations`, `category:purchases` |
| `has:`                                                                                                                                                                                                                           | 次を含むメールを検索します。<br/>添付ファイル, 埋め込み画像, YouTube 動画, ドライブ ファイル, Google ドキュメント, Google スプレッドシート, Google スライド                         | `has:attachment`, `has:youtube`, `has:drive`, `has:document`, `has:spreadsheet`, `has:presentation`                                                |
| `list:`                                                                                                                                                                                                                          | メーリング リストからのメールを検索します。                                                                                                                                         | `list:info@example.com`                                                                                                                            |
| `filename:`                                                                                                                                                                                                                      | 特定の名前またはファイル形式の添付ファイルを含むメールを検索します。                                                                                                                | `filename:pdf`, `filename:homework.txt`                                                                                                            |
| `" "`                                                                                                                                                                                                                            | 指定した単語やフレーズを含むメールを検索します。                                                                                                                                    | `"dinner and movie tonight"`                                                                                                                       |
| `( )`                                                                                                                                                                                                                            | 複数のキーワードをグループ化します                                                                                                                                                  | `subject:(dinner movie)`                                                                                                                           |
| `in:anywhere`                                                                                                                                                                                                                    | Gmail 全体でメールを検索します。これには、`[迷惑メール]` と `[ゴミ箱]` 内のメールも含まれます。                                                                                     | `in:anywhere movie`                                                                                                                                |
| `in:archive`                                                                                                                                                                                                                     | アーカイブしたメールを検索します。                                                                                                                                                  | `in:archive payment reminder`                                                                                                                      |
| `in:snoozed`                                                                                                                                                                                                                     | スヌーズしたメールを検索します。                                                                                                                                                    | `in:snoozed birthday reminder`                                                                                                                     |
| `is:muted`                                                                                                                                                                                                                       | ミュートしたメールを検索します。                                                                                                                                                    | `is:muted subject:team celebration`                                                                                                                |
| `is:`                                                                                                                                                                                                                            | 以下のステータスでメールを検索します。<br/>重要, スター付き, 未読, 既読                                                                                                             | `is:important`, `is:starred`, `is:unread`, `is:read`                                                                                               |
| `has:yellow-star`, `has:orange-star`, `has:red-star`, `has:purple-star`, `has:blue-star`, `has:green-star`, `has:red-bang`, `has:orange-guillemet`, `has:yellow-bang`, `has:green-check`, `has:blue-info`, `has:purple-question` | 複数の種類のスターを設定している場合は、スターの種類ごとにメールを検索できます。詳しくは、[Gmail でのスター付きメール](https://support.google.com/mail/answer/5904)をご覧ください。 | `has:yellow-star OR has:purple-question`                                                                                                           |
| `deliveredto:`                                                                                                                                                                                                                   | 特定のメールアドレスに送信されたメールを検索します。                                                                                                                                | `deliveredto:username@example.com`                                                                                                                 |
| `size:`, `larger:`, `smaller:`                                                                                                                                                                                                   | サイズでメールを検索します。                                                                                                                                                        | `size:1000000`, `larger:10M`                                                                                                                       |
| `+`                                                                                                                                                                                                                              | 単語と完全に一致するメールを検索します。                                                                                                                                            | `+unicorn`                                                                                                                                         |
| `rfc822msgid`                                                                                                                                                                                                                    | 特定の Message-ID ヘッダーを含むメールを検索します。                                                                                                                                | `rfc822msgid:200503292@example.com`                                                                                                                |
| `has:userlabels`, `has:nouserlabels`                                                                                                                                                                                             | ラベルが付いているメールまたは付いていないメールを検索します。ラベルは、スレッド全体に追加されるのではなく、個別のメールに追加されます。                                            | `has:userlabels`, `has:nouserlabels`                                                                                                               |
| `label:encryptedmail`                                                                                                                                                                                                            | クライアントサイド暗号化を適用して送信されたメールを探します。                                                                                                                      | `label:encryptedmail`                                                                                                                              |
